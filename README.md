# ChemiCalc: The Universal Element Solver

![ChemiCalc Banner](https://via.placeholder.com/1200x400/0a0e17/00f3ff?text=ChemiCalc+Dashboard)

## 🧪 Introduction
**ChemiCalc** is not your average chemistry tool. It is a futuristic, high-performance **Laboratory Dashboard** designed for students and professionals who demand both style and substance. Built with a "Sci-Fi" aesthetic, it transforms mundane calculations into an immersive experience, featuring neon accents, glassmorphism, and a layout reminiscent of a spaceship's control panel.

## 🚀 Tech Stack
This project was built using cutting-edge modern web technologies:
- **React (Vite)**: For lightning-fast performance and component-based architecture.
- **Tailwind CSS**: For the custom "Sci-Fi" design system and responsive styling.
- **Lucide React**: For sleek, modern iconography.
- **Math.js**: Powering the complex calculation engine.

## ⚡ Key Capabilities

### 1. Interactive Periodic Table Keyboard
A collapsible, interactive grid that puts the elements at your fingertips. Click any element (e.g., "He", "Fe") to instantly inject its precise atomic mass into your calculations. Hover for detailed electron configurations and group data.

### 2. Advanced Formula Engine
Forget memorizing constants. The Formula Engine handles the heavy lifting for:
- **Gas Laws**: Boyle’s, Charles’s, and Ideal Gas Law (PV=nRT).
- **Stoichiometry**: Molarity and Molality calculations.
- **Thermodynamics**: Gibbs Free Energy and Enthalpy.
Simply select a formula, enter your known variables, and let the engine solve for the unknown.

### 3. Constants Quick-Dock
A persistent sidebar provides instant access to the fundamental constants of the universe. One click inserts values for:
- Avogadro’s Number ($6.022 \times 10^{23}$)
- Planck’s Constant ($h$)
- Gas Constant ($R$)
- Faraday Constant ($F$)

### 4. Molar Mass Calculator
A dedicated parsing engine that understands chemical syntax. Type any formula (e.g., `H2SO4`, `C6H12O6`), and ChemiCalc will parse the string, sum the atomic masses, and provide the exact molar mass instantly.
